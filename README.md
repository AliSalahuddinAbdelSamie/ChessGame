# Java Chess Engine

A two-player chess engine built in Java featuring an interactive GUI developed with Swing. The project emphasizes object-oriented design, clean architecture, and modular code with the use of multiple design patterns. Ideal for learning game logic, UI development, and design principles.

## Features

- Full implementation of standard chess rules  
- Interactive **Graphical User Interface** using Java Swing  
- Two-player local gameplay  
- Object-oriented structure for modular and maintainable code  
- Use of design patterns (e.g., Strategy, Factory, Singleton)  
- Real-time move validation and turn tracking  
- Visual highlights for selected pieces and valid moves  

## Technologies Used

- **Java** — Core language  
- **Swing** — For building the GUI  
- **IntelliJ IDEA** — Development environment
